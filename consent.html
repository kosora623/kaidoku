χ読（かいどく）ご利用前の同意

絡まった英文を、ほどいて読む。ご利用を開始する前に、外部へのテキスト送信についてご確認ください。

送信するデータと取り扱いについて

  • 難文マーク判定での送信：あなたが拡張機能のボタンを押したページに限り、本文から抽出した英文候補（8 語以上・最大 3 回分割）を Google Gemini API（gemini-3.1-flash-lite）へ送信して構文を判定します。ボタンを押していないページや、パスワード・入力フォーム・数式行・コード・参考文献は送信しません。
  • タップ時の構造解析での送信：ページ上でマークした文をタップしたときに、その 1 文を構造解析（S・V・O・C と括弧の図解生成）のために Google Gemini API へ送信します。
  • 単語の意味取得での送信：解析パネル内の単語をタップしたときに、その単語と元の 1 文（略語の場合はページ内で見つかった正式名称を含む）を文脈に合う意味の取得のため Google Gemini API へ送信します。
  • 「訳を見る」での日本語訳取得での送信：解析パネルの「訳を見る」ボタンを押したときに限り、その 1 文とページ内で見つかった略語の定義を日本語訳の生成のため Google Gemini API へ送信します。
  • 送信先：Google の Gemini API（generativelanguage.googleapis.com）のみに送信します。χ読独自の外部サーバーへは一切送信しません。
  • ローカル保存とキャッシュ：難文判定の結果は URL ごとに手元のブラウザ（IndexedDB）へキャッシュし、同じページで再度 API を呼ばないようにします。学習記録もすべて手元のブラウザ内にのみ保存します。
  • 同意の撤回：設定画面（options.html）からいつでも同意の撤回、API キーの削除、キャッシュの全消去が可能です。
無料枠の API キーに関するご注意：
Google AI Studio の無料枠で発行した API キーを使用する場合、送信した英文が Google の製品改善に使用される場合があります。専用の別プロジェクトで発行した API キーのご利用をおすすめします。

※ API キーを設定すると高精度なクラウド判定が有効になります。未設定のまま進んだ場合は、ルールベースの簡易マークおよび Gemini Nano（精度が低い実験的なモード）で動作します。
