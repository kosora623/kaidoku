# χ読（かいどく）アイコンの置き場所と差し替え手順

## ファイルの置き場所

アイコン関連ファイルはすべて `public/icons/` に置いています。`npm run build` を実行すると、`public/` 配下がそのまま `dist/` にコピーされ、[public/manifest.json](../public/manifest.json) の `icons` と `action.default_icon` から参照されます。

| ファイルパス | サイズ | 形式 | 主な表示箇所 |
| --- | --- | --- | --- |
| `public/icons/icon.svg` | 128×128（ベクター） | SVG | 元データ（デザイン差し替え時のベース） |
| `public/icons/icon-16.png` | 16×16 px | PNG | ツールバー（標準DPI）・ファビコン |
| `public/icons/icon-32.png` | 32×32 px | PNG | ツールバー（高DPI / Windows 150〜200% 表示） |
| `public/icons/icon-48.png` | 48×48 px | PNG | `chrome://extensions` の拡張機能管理一覧 |
| `public/icons/icon-128.png` | 128×128 px | PNG | インストール確認ダイアログ・Chrome Web Store |

## 作成・書き出し時の仕様と余白の目安

- **ファイル形式**：PNG（RGBA・透過背景・sRGB）
- **サイズ**：必ず正方形の等倍ピクセル（`16×16`、`32×32`、`48×48`、`128×128`）で書き出す
- **余白の目安**：
  - **128×128 px（ストア／一覧表示用）**：
    - 全面ベタ塗りよりも、キャンバス外周に **約 5〜12%（6〜16 px）の透過余白** を残すと、Chrome の他拡張と並べたときに大きく見えすぎず整います（Chrome Web Store の推奨ガイドラインは 128×128 の中に 96×96 本体＋周囲 16 px 余白）。
    - 角丸の四角形にする場合は `128×128` に対して角丸半径 `24〜28 px` 程度が収まりやすいです。
    - 仮アイコン（`icon.svg`）では `128×128` キャンバスに対して外周 `6 px` 余白・本体 `116×116`・角丸 `rx=28` で配置しています。
  - **16×16 px / 32×32 px（ツールバー用）**：
    - 小さいサイズでは細い線や細かい装飾が潰れるため、**線幅を太め**（`128px` 基準で 10〜14 px 相当）にし、外周の透過余白は最小限（0〜1 px 程度）に抑えると視認性が上がります。
    - ライトテーマ／ダークテーマどちらのツールバーでも見分けやすいよう、背景付きの図形にするか明暗差をはっきりさせてください。

## アイコンを差し替える手順

1. 新しいデザインの PNG を次の 4 ファイル名で `public/icons/` に上書き保存します（元データがある場合は `public/icons/icon.svg` も差し替えます）。
   - `public/icons/icon-16.png`
   - `public/icons/icon-32.png`
   - `public/icons/icon-48.png`
   - `public/icons/icon-128.png`
2. ビルドを実行して `dist/icons/` へ反映します。
   ```bash
   npm run build
   ```
3. Chrome の `chrome://extensions` を開き、χ読の「更新（再読み込み）」ボタンを押して、ツールバーと拡張一覧のアイコンが切り替わったことを確認します。
