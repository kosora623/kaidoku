χ読（かいどく）設定

χ読の構造解析・難文判定はクラウドの Gemini API（gemini-3.1-flash-lite）を既定で使用します。API キー未設定時はルールベース簡易マークおよび Gemini Nano（精度が低い実験的なモード）で動作します。

無料枠の API キーに関するご注意：
Google AI Studio の無料枠で発行した API キーを使用する場合、送信した英文が Google の製品改善に使用される場合があります。専用の別プロジェクトで発行した API キーのご利用をおすすめします。
